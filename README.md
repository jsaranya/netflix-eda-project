# Netflix EDA Project

A beginner data science project analyzing Netflix's movie and TV show catalog using Python (pandas, matplotlib, seaborn).

## Dataset
Netflix Movies and TV Shows dataset from Kaggle:
https://www.kaggle.com/datasets/shivamb/netflix-shows

## What this project does
- Cleans and prepares the raw dataset (handles missing values, fixes data types)
- Explores the data to answer key questions:
  - How many Movies vs TV Shows are on Netflix?
  - Which countries produce the most content?
  - What are the most common genres?
  - How has content added to Netflix changed over the years?
- Visualizes findings with charts

## Key Insight
Netflix has more than twice as many Movies (~6,131) as TV Shows (~2,676) — 
roughly a 2:1 ratio. This is likely because movies are quicker to watch, 
so Netflix needs a larger volume of them to keep viewers engaged, compared 
to TV shows where one series can hold someone's attention for many episodes.

## Tools Used
Python, pandas, matplotlib, seaborn
